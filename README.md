# thomasmcleary.com

Personal site for Thomas Cleary — software engineer at Orases in Frederick, Maryland.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- Markdown writing in `content/writing/`

## Local development

```bash
npm install
npm run dev
```

## Writing

Published pieces live in `content/writing/*.md`.

```markdown
---
title: "Title"
subtitle: "Optional subtitle"
date: 2025-01-21
---

Body in markdown.
```

Drafts can sit in `content/writing/drafts/` and are not published.
